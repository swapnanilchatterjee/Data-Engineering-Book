# 🎬 Netflix Content Catalog & Popularity Analytics

Welcome to the **Netflix Analysis** module in **The Data Engineering Book**! 🍿

This data science project explores global entertainment catalogs to uncover release distributions, genre frequency, rating trends, and movie popularity metrics.

---

## 📂 Module Files
- **`mymoviedb.csv`**: Comprehensive movie database containing titles, release dates, vote counts, vote averages, popularity scores, and genres.
- **`Netflix_Analysis.ipynb`**: End-to-end exploratory analysis notebook with data cleaning, genre splitting, and Seaborn/Matplotlib visualizations.

---

## 📊 Exploratory Insights
1. **Genre Dominance**: Extracting and exploding delimited genre tags to find top produced categories (Drama, Comedy, Action).
2. **Rating Distributions**: Visualizing `vote_average` histograms and identifying critically acclaimed titles.
3. **Popularity vs. Rating Correlation**: Measuring whether high popularity correlates with critical acclaim.
4. **Annual Production Timeline**: Tracking catalog release volume across historical decades.

---

## 🚀 How to Run
```bash
jupyter notebook Netflix_Analysis.ipynb
```
