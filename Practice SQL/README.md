# 💾 Practice SQL: Advanced Query Engineering & Interview Questions

Welcome to the **Practice SQL** module of **The Data Engineering Book**! 🚀

This module is designed to master relational data engineering, analytical SQL, window functions, and real-world query optimization.

---

## 📂 Module Files
- **`Practice Common 15.sql`**: The 15 most frequently asked SQL interview questions with production query solutions.
- **`Common 15 Data.sql`**: Complete DDL table schemas and sample insert datasets (`customers`, `orders`, `employees`, `departments`) to spin up a local practice database.
- **`Practice all types.sql`**: Comprehensive query suite covering joins, CTEs, aggregation filters, conditional logic, and subqueries.

---

## 🧠 Key SQL Concepts Covered
1. **Window Functions**: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LAG()`, `LEAD()`, running totals.
2. **Common Table Expressions (CTEs)**: Recursive CTEs, modular query design, and multi-step aggregations.
3. **Date & Time Manipulations**: `EXTRACT(MONTH FROM order_date)`, `TO_CHAR()`, year-over-year trends.
4. **Relational Joins**: Multi-table inner, left outer, full joins, and self-joins.
5. **Grouping Sets & Filter Clauses**: `GROUP BY`, `HAVING`, conditional aggregations (`COUNT(CASE WHEN...)`).

---

## 🚀 How to Run
Execute these scripts in **PostgreSQL**, **MySQL**, or any ANSI SQL relational database management system (SSMS, pgAdmin, DBeaver).
