# 🏥 Healthcare Expense & Clinical Readmission Analytics

Welcome to the **Health Expenses** project in **The Data Engineering Book**! 🩺

This project analyzes clinical inpatient records and actuarial data to understand length of stay, medication loads, and readmission risk factors.

---

## 📂 Module Files
- **`Diabetic_data.csv`** & **`cleaned_diabetic_data.csv`**: Over 100,000 clinical inpatient records spanning 50 attributes.
- **`Health cleaning.sql`**: SQL cleaning and standardization script for patient admissions and diagnoses.
- **`Health_Expenses.ipynb`**: Exploratory data analysis notebook with statistical demographic summaries.
- **`Health expenses.pbix`**: Interactive Power BI dashboard visualizing readmissions, age demographics, and medical specialty metrics.

---

## 🎯 Key Clinical & Actuarial Insights
1. **Length of Stay vs Procedures**: Correlating hospital duration with number of lab procedures and medications.
2. **Readmission Risk Factors**: Evaluating diabetic patient readmission rates within 30 days.
3. **Data Cleansing**: Handling missing medical specialties, payer codes, and normalizing diagnosis codes.

---

## 🚀 How to Run
- Run `Health_Expenses.ipynb` in Jupyter Notebook.
- Execute `Health cleaning.sql` in PostgreSQL or SQL Server.
- Open `Health expenses.pbix` in Power BI Desktop.
