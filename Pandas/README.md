# 🐼 Pandas: Data Wrangling & Exploratory Feature Pipelines

Welcome to the **Pandas** module of **The Data Engineering Book**! 🐍

This hands-on interactive guide covers end-to-end data preparation, indexing, filtering, and aggregation in Python.

---

## 📂 Module Files
- **`Pandas_Tutorial.ipynb`**: Complete interactive Jupyter notebook with 67 executed cells covering fundamentals to advanced data transformations.

---

## 📚 Key Topics Covered
1. **DataFrame & Series Construction**: Creating structures from dictionaries, lists, and CSVs.
2. **Indexing & Slicing**: `.loc` (label-based) vs `.iloc` (integer-location based) indexing mechanics.
3. **Missing Value Imputation**: `isna()`, `dropna()`, `fillna()`, and forward/backward interpolation.
4. **Conditional Filtering**: Complex Boolean masking, `.isin()`, and regex string matching.
5. **Group-By & Aggregations**: Multi-column grouping, named aggregations, and pivot tables.
6. **Merging & Concatenation**: Inner, outer, left joins, and vertical stacking.

---

## 🚀 How to Run
```bash
jupyter notebook Pandas_Tutorial.ipynb
```
